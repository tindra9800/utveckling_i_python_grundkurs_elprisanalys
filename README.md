# Elprisanalys för dagens och gårdagens elpriser

1. Mål
    Analysera dagens och gårdagens elpriser. Högsta och lägsta pris samt när det är som dyrast och billigast att använda el.

2. Metod
    1. Hämta data från API
    2. (fixa sen) Spara i CSV format
    3. Analysera elpriset
    4. Printa ut diagram och resultat med matplotlib

3. Resultat
    Programmet kan printa ut dagens och gårdagens elpriser i de fyra olika elområderna. Jämföra dyraste samt billigaste priset och printa ut ett visuellt diagram över elpriset under dygnet. 

    Generellt sätt så är det billigast elpriser mellan 00:00 - 04:00 och dyrast mellan 06:00-09:00 och 18:00-22:00.

4. Analys
    Resultatet visar att pyhton enkelt kunde ta in datan från API:n och analysera den.
